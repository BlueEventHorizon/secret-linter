## S01

次の 3 つを、報告する。位置は、入力の行番号である。

| 値                    | 期待の種別      | 行 |
| --------------------- | --------------- | -- |
| `テスト太郎`          | `person_name`   | 7  |
| `ほげ商事`            | `company_name`  | 8  |
| `foo-bar-prod-assets` | `resource_name` | 9  |

- 値は、本文の文字列のまま報告される（要約・補正されていない）
- 1 回の呼び出しで 1 件ずつ報告されている（`ai_events/` に、候補ごとに 1 件の `accepted` がある）
- 種別は、`resource_name` が `other_ai` になるなど、揺れてよい。見落としと、種別の揺れを区別する
- `ai_check.py` が 0 で終わる
- 最終応答に、値・本文・件数・位置が含まれない

## S02

| 値                                      | 理由                   |
| --------------------------------------- | ---------------------- |
| `<your-api-key>`・`REPLACE_ME`          | 明示的なプレースホルダ |
| `localhost`・`https://example.com/docs` | 予約された例示値       |
| `<氏名>`・`<会社名>`                    | 形だけを示す記述       |

- 0 件でも、`ai_check.py` が 0 で終わる（候補が 0 件でも `ai_finish.py` を呼ぶ）
- 最終応答に、値・本文・件数・位置が含まれない
